ReThread / ReSourcePK — Software Requirements
=============================================

This project is implemented in JavaScript/TypeScript, not Python. This file is
an inventory for developers; do not install it with pip. Use npm ci in each
package directory to install the exact dependency tree from its lockfile.

BASE RUNTIME
------------
Node.js: >=24 and <27 (Node.js 24 recommended)
npm: version shipped with the selected Node.js installation
PostgreSQL: 17 recommended for local development and CI

EXTERNAL SERVICES AND LOCAL TOOLS
---------------------------------
PostgreSQL database: required by the backend. Supabase can provide the hosted
PostgreSQL database; local PostgreSQL is suitable for development and tests.
Polygon Amoy RPC endpoint: required when connecting to the Amoy blockchain.
Polygon Amoy deployed PassportRegistry contract: required for anchoring hashes.
Dedicated blockchain signer wallet and private key: required by the worker;
keep the private key in local .motem or a hosting provider's secret settings.
Google OAuth Web client: optional, for Google sign-in.
Gmail SMTP app password: optional, for sending verification and invitation mail.
RapidGateway account and webhook signing salt: optional, for payment checkout.
Supabase Storage project and service-role key: optional, for listing images.
Playwright Chromium: required only for browser end-to-end tests; install with
the Playwright browser installer when running those tests locally.

SECURITY AND VERSIONING
-----------------------
Never put credentials in this file, source control, or frontend environment
variables. Keep private local values in the ignored .motem file and configure
deployed services with their secret environment settings. package-lock.json and
contracts/package-lock.json record the complete resolved package trees,
including transitive dependencies; npm ci installs those pinned trees.

The separate ReSourcePK_Frontend repository has its own package.json and
package-lock.json. Install its dependencies from that repository with npm ci.
